# LMEX International

Official web application and consignment tracking portal for **LMEX International** courier and cargo logistics services.

## Overview
- **Home (`/`)**: Corporate capabilities, global flight network, security standards, and responsive navigation.
- **Track Order (`/track-order`)**: Consignment radar with live milestone tracking, visual hub routing, status indicators, and delivery timeline.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Inter font system

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
